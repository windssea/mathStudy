# 账号与学习同步

实现日期：2026-10-19。本文记录已实现功能；架构基线中的考试、家长和教师角色未在本次开放。

## 登录与数据归属

用户在 `/account` 使用邮箱和至少 10 字符密码注册、登录。当前邮箱仅作为账号标识，不代表已验证邮箱所有权；不发送验证或找回邮件。没有第三方账号依赖。请保存登录信息，后续接入邮件服务后再开放邮箱验证和找回流程。

Better Auth 1.7.10 使用原生 D1 适配器管理 `user`、`account`、`session`、`verification` 和 `rateLimit` 表。密码使用库默认的 scrypt 加盐哈希，构建包使用 `node:crypto` 的实现；不存明文密码。生产会话使用 HTTPS、HttpOnly、SameSite=Lax Cookie，有效期 7 天，活跃时按 1 天更新。浏览器本地存储不保存会话令牌。退出删除当前会话，不注销其他设备。

Worker API 拒绝跨来源写入；登录限制为同 IP 每分钟 10 次，注册为每 10 分钟 5 次，计数保存在 D1。生产签名密钥 `AUTH_SECRET` 是 Worker Secret；它不是 Cloudflare 部署令牌。只开放注册、登录、退出及库的改密接口，未开放账号枚举和管理接口。

## D1 数据与合并

迁移 `0003-authentication.sql` 依据安装版本的 Better Auth schema 生成；`0004-learning-events.sql` 新增 `learning_events`。数据按服务端会话的 `user_id` 与 `edition_id` 查询。每个事件有唯一 ID、实体 ID、类型、发生时间、接收时间和 JSON 内容；`(user_id,id)` 主键保证重传不会重复计数。索引按账号、教材和时间读取。

事件包含访问课节、完成课节、提交答案、使用提示及旧版记录导入。所有课节和题目 ID 都需属于已发布教材；新答题事件必须提供原始答案，服务端重新判分，不接收客户端自报的分数。完成课节取并集，最近访问按发生时间确定，作答逐条保留。系统不上传整份本机快照覆盖云端。设备时间超前超过 5 分钟时会被限制；正常情况下按设备时间及事件 ID 确定顺序，建议设备启用自动校时。

教材内容继续使用发布版本隔离，学习事件绑定教材版次，避免同一教材更新课节内容时清空进度。将来添加教材时需要按相同契约传入独立 `editionId`；当前只开放首期教材。

## 客户端同步与游客导入

浏览器缓存服务器快照，每个待上传事件单独保存为 localStorage 条目，并按账号隔离。登录后先读取当前账号，再发送最多 100 个事件；服务端成功确认 ID 后才移除相应待上传条目。请求 15 秒超时，失败按递增间隔重试，最长间隔 30 秒。页面重新获得焦点、网络恢复、前台每 30 秒会检查会话并拉取最新记录。离线时可保留已产生的学习事件；新的自动判题仍需网络。

同步请求携带预期账号 ID，服务端将它和当前会话核对。另一个标签页切换账号时，旧请求返回 409，原账号队列继续保留；旧答题请求的延迟响应也只写回原账号缓存。退出及会话过期后界面切回游客记录。共享电脑请退出账号；每个账号的本机缓存并非加密保险库。

游客无需登录即可学习。本机原来的两个预览版本记录会迁移到游客事件，原始 localStorage 键保留。登录后不自动上传游客数据，用户在账号页明确选择“合并本机学习记录”。事件 ID 保持稳定，多次合并不重复累计。旧版只有判分结论、没有原始答案的条目使用 `legacy` 类型，显示“本机导入”，不冒充服务端重判。该平台用于学习反馈，不提供防作弊成绩认证。

## 答题历史与错题

登录后提交答案时先写入 D1，再返回判题结果；同一事件进入客户端同步队列重试时不会重复插入。使用提示或直接查看讲解也会记录辅助事件。

答错或使用提示的题进入“待复习”；点击“重新独立作答”清空本次提示与输入，独立答对后转入“已掌握”，保留曾错次数及历史足迹。首次未看提示独立答对才计入“独立做对”，后续订正不改变首次证据。最近答题记录展示最近 100 次作答、当时填写的答案、是否借助提示、时间和判分来源；D1 保留完整事件，当前接口会读取并归并完整事件，再返回聚合及最近 100 条。

## 接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/auth/sign-up/email` | 注册，昵称不超过 40 字符 |
| `POST /api/auth/sign-in/email` | 登录 |
| `POST /api/auth/sign-out` | 注销当前会话 |
| `GET /api/v1/account` | 当前账号摘要与服务可用标记 |
| `GET /api/v1/me/progress` | 当前教材学习聚合 |
| `POST /api/v1/me/sync` | 提交事件并返回合并后的聚合 |
| `POST /api/v1/questions/:id/check` | 判题；已登录时同时落库 |

`/me/*` 及已登录判题需 `X-MathStudy-Account` 与会话一致。同步请求为 `{editionId,events}`，返回 `{snapshot,acknowledged,serverTime}`，外层沿用 `{data,requestId}`。未登录 401、账号不匹配 409、非法事件 400、超过 160 KiB 413；正常每批不超过 100 个事件。

## 维护和验证

执行 `pnpm test` 验证真实 SQLite 上的账号库和 D1 形状适配器；执行 `pnpm exec tsx scripts/smoke-sync.ts --origin <地址>` 验证真实 Worker、D1 与两组独立 Cookie 会话。手动冒烟会创建测试账号并保留测试事件，不触碰用户已有记录、不发送邮件。`--save-fixture` 将仅供浏览器验收的随机账号保存在被忽略的 `tmp/qa-sync.json`，不会打印凭据。

当前按账号读取全部事件适合首期规模；后续事件量增长时需要增加服务端聚合检查点及历史分页，不能以直接删除旧事件代替归档。生产 D1 的备份与恢复使用 Cloudflare 的恢复能力；内容种子不修改学习事件表。升级 Better Auth 时先核对其 schema 变化，再增加迁移和会话回归测试。
