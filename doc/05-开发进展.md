## 第二单元实现约定

教材知识范围为书内 p.18–41，附 p.42–43 实践活动。所有题库题目仍标为原创，教学顺序依据用户提供的 2026 年版 PDF。

- 测量演示支持 6×4 长方形与 3–4–5 三角形。记录每条边；直尺起点对准 0；展开后的线段与原边使用同一像素比例。图形按比例示意，屏幕厘米不作为实体尺使用。
- 面积演示支持逐格、逐排、铺满和清空；前后步骤能重现铺格数量。长宽修改后清空探索状态，防止沿用旧公式或完成状态。
- 同一 8×4 厘米卡片分别铺 32 个 1 平方厘米方格、8 个 4 平方厘米方格，卡片大小保持不变。面积换算单独用 10×10 模型解释进率 100。
- 剪角图解分完整面积、剪去面积、剩余 L 形三步；正方形保持等比例。靠墙围栏明确去掉靠墙长边。同周长和同面积题列出全部整数边长组合，配合当前图形和表格比较。
- 首页、目录、课节路线、下一课与学习记录不再限制在第一单元；第一单元末尾可接第二单元，第二单元末尾可接探索活动。课节 API 按教学内容中的题目顺序返回随堂题。
- 当前版本优先读取新进度键，缺失时读取第一单元预览键；首次写入保存为新版键，不删除旧记录。支持第二单元及活动的完成记录。

核心文件为 `unit2-lessons.json`、`GeometryLessonPlayer.tsx`、`GeometryProblemDrawing.tsx` 与 `unit2-questions.ts`。几何量和整数枚举位于 `math-core`，测量与铺格讲解步骤位于 `animation-engine`。

## 验证

84 项自动化测试通过。数据库集成检查使用真实 SQLite 执行全部迁移、反复同步内容、校验外键和 API 读取，确认数据库不完整时不会回退示例数据。账号检查覆盖真实密码哈希、双会话、单会话退出、会话过期及篡改、登录限流、账号隔离、防跨来源写入、服务端重判、幂等合并和错题订正。客户端检查覆盖游客显式导入、断网队列跨刷新保留、恢复同步、切换账号及延迟答题响应隔离。原有 71 项数学、内容、API、组件与几何演示回归保留。

真实浏览器复核包含桌面周长测量与展开、375 像素宽度下的面积铺格、剪角难题、定面积枚举题和活动拼法切换，以及 768 像素宽度的活动表格。375/768 两种视窗均未出现文档横向溢出；复核后已恢复默认视窗。开发服务曾因依赖预构建停滞显示白屏，使用 `pnpm --filter @mathstudy/web dev --force` 重新预构建后恢复。以上为浏览器响应式验证，尚不替代实体触屏设备测试。
