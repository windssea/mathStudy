## 结论

保留 Nova / Radix、Lucide、薄荷绿与纸面底色，以及天蓝、杏黄、珊瑚分类色。进一步重构的重点依次是：学习反馈准确、教学画布与阅读空间、连续练习、图示教学深度。无需更换技术栈，也不应再增加一套 UI 或动画方案。

Impeccable 4.8.0 将这类页面归入 Operate；方法说明兼有 Read。对应的设计要求是任务清楚、控件一致、阅读稳定、按需解释。活泼感来自数学对象、有限的语义配色和明确反馈，避免装饰占据演示空间。此轮采用其 `audit` 技术审查流程及 `operate` 指南，不是需要双评估代理的 `critique` 流程。

## 分阶段改进计划

### 第一批：修复可信度与基本阅读

范围 A01–A04；先解决这四项，再推进页面结构的下一次迁移。

- 辅助学习：明确查看提示、打开方法、查看解析、自主核对的事件边界；自动收到解释不算查看。历史记录保留，不凭猜测批量改写旧辅助状态。
- 工作区：为五类课程播放器、方法演示共用空间规则。低高度时先收起次要参数与完整知识说明，右侧只显示当前原因；主图和前后步骤始终可达。
- 字号：自然语言题干 22–24px，正文 18px，常用 UI 16–17px；短算式可使用约 30–36px 的独立规则。图中关键标签实际渲染建议不低于 16px，主要数值/说明达到 18px；不能只检查 SVG 源码里的 font-size。
- 目录：稳定编号、颜色与定位；未开放课程直接引导到已开放内容。

对应能力：`impeccable harden`、`layout`、`typeset`、`adapt`。不把工具命令作为必须安装新依赖的理由。

### 第二批：练习和导航连续完成

范围 A05–A07、A09、A12。

- 练习保留左题右答。主操作固定为核对/下一题；帮助按需显示，切回作答恢复原输入与分栏。默认短轮次，明确当前题数、继续与重练。
- 首页保留左单元导航，右侧采用紧凑题型行，正常笔记本首屏目标至少可辨 4 个专题入口；学习顺序优先于按内容名称分组的偶然顺序。
- 题库采用左列表右预览，页码或前后批次控制固定可达；列表提供关键条件与必要小图，不堆放重复“商与余数”标题卡。
- URL 管理题型、当前题与筛选；草稿在必要范围内持久化并按身份隔离。账号切换清理身份相关状态；同步仍复用原协议。
- 放大关闭返回触发器，路由改变有标题/焦点提示；作图增加方向键与撤销。错误提供简短可执行的恢复操作。

对应能力：`impeccable distill`、`harden`、`clarify`。

### 第三批：先把两组方法真正讲懂

范围 A08。试点 U01 余数与验算、U02 围栏与靠墙，通过后扩展其余方法。

| 方法 | 学生先看见什么 | 分步变化 | 易错反例 |
| --- | --- | --- | --- |
| 余数与验算 | 可分成整份的对象、剩余对象、每份大小 | 分组 → 显示剩余 → 检查能否再成一份 → 对应算式和验算 | 剩余量达到除数时，再组成一份；解释商为什么要加 1 |
| 围栏与靠墙 | 地块边界、墙的位置、真正需要围的边 | 标记边界 → 排除靠墙边 → 展开需围部分 → 对应长度和算式 | 墙边误计或漏计；移动墙的位置观察需要围的边如何变化 |

每一帧只讲一个变化，标明本步操作和原因；同一对象、数值、线型贯穿前后步骤。至少提供一组正确情境与一组针对性错误情境，判断后解释“错在哪里”，再用不同数字独立练习。例题明确标注为例题，避免混同当前题答案。

完整方法不强制统一三步；根据知识结构选择步骤数。主要数学关系由纯函数和确定性状态定义，SVG 表达状态，播放或 Motion 不拥有数学状态。先通过内容核对及界面验收，再做儿童试用；内部审查不能代替真实理解效果验证。

### 第四批：主题、性能和统一收尾

范围 A10、A11、A13。

- 全部公共控件回到同一套 token；给深色数学画布配套颜色，而不是只换外层底色。减少粗侧边线与重复面板，但保留数学语义。
- 记录页按实际记录取题、分批呈现；题库按筛选分页读取。先量请求体积和交互延迟，再决定是否需要虚拟列表。
- 根据现有代码补齐精简的设计系统说明，可继续纳入第 14/18 号文档；如采用 Impeccable 的 PRODUCT.md / DESIGN.md，记录同一份既有决策，避免两套互相冲突的规范。
- 最后运行 `impeccable polish`，复审视觉与交互；不在此阶段重新选择品牌或技术栈。

| 独立纠错 | 错答 → 未打开任何帮助 → 自行改对，显示独立答对；打开方法/提示/解析后再答对，显示辅助答对；自主核对沿用既有政策 |
| 草稿和来源 | 题 2 输入未提交 → 去记录/登录 → 返回，当前题和输入可恢复；题库搜索/重置/前进后退与 URL 一致；返回列表保留原筛选 |
| 键盘 | 放大、前后步骤、Escape 关闭后回到原触发器；分栏可键盘调整；方格一个 Tab 入口并可方向键移动、切换、撤销 |
| 教学 | 两组试点逐帧核对数学关系、边界条件、错误反例；学生能看到变化与原因；之后扩展其余 40 类，不把“有图”当完成 |
| 主题和触控 | 浅/深色主图、当前步、错误均可辨；关键操作目标至少 44px。布局模拟之外补真实或可合成触摸检查，说明设备与仍未覆盖的手势 |
| 数据与回归 | 历史题 ID、判分、错题、账号隔离、D1 同步保持兼容；新增测试只针对真实行为及数学关系。每批运行相关测试、类型、格式、构建；涉及数据再跑内容与 D1 检查 |

## 保留的优点

共享 QuestionRunner、分栏和确定性数学引擎为后续改进提供了稳定基础；方法与解析已经能够按需显示，切换页签可保留当前输入；Nova、Lucide、加载骨架、字段标签及浅深主题方向正确。后续工作应围绕这些基础收敛实现。
