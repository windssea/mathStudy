# UI 改进实施与验收

日期：2026-10-29。对应[第 19 号审核计划](19-全站UI审核与改进计划.md)。本轮完成本地开发与验收，尚未推送或发布。

## 分工与交付

三个开发 agent 分别负责练习状态、工作区设计、图示教学；主 agent 负责题库与记录、公共恢复操作、接口分页、集成复审和浏览器验收。共享目录按文件划分所有权，第二轮交叉审查修正了复习刷新、批次返回及登录返回路径问题。

继续采用 Nova / Radix、Lucide、现有分栏和数学引擎，没有新增依赖、数据库迁移或同步协议。数学状态仍由纯函数及确定性故事板控制，题目 ID、旧链接和历史学习事件保留。

| 审核项 | 本轮实现 |
| --- | --- |
| A01 辅助误记 | 区分已取得解析与实际查看帮助；自行订正不再误记为辅助。异步核对期间查看帮助也正确更新状态；近期独立掌握与历史首次答对保持不同语义 |
| A02 画布压缩 | 五类播放器收起低频参数，当前步骤的原因通过共享 LessonNarration 显示在右侧；完整知识按需展开，主图获得明确空间预算 |
| A03 字号 | 自然语言题干固定 24px、短算式 32px；关键图示标签按实际 SVG 缩放补偿至至少 16px，主数值至少 18px；窄分块采用编号对应完整标签 |
| A04 单元编号 | 编号与颜色按稳定单元 ID 计算，活动和搜索不改变序号；未开课的第六单元提供现有方法、练习入口 |
| A05 连续性 | 当前题与批次写入 URL；同一标签页内按身份及版本保存草稿，刷新、跨页和返回可恢复；账号改变清理草稿，不改学习历史。题库、记录页筛选和分页均可恢复来源 |
| A06 焦点 | 关闭放大后返回原触发器并保留步骤；路由更新页面标题及主内容焦点；平板导航保留文字 |
| A07 导航密度 | 首页按原有学习顺序显示紧凑题型行；题库改左选题、右预览，分页及开始练习固定可达；明确区分解题类型与作答形式 |
| A08 教学图示 | 余数与围栏各有五步对象推演、错误对照和换数/换墙方向自查；强化分组、速度、试商、数量依赖等模型，并修正条形图比例。为余数专题 15 道题建立明确子技能映射，使用独立例题，不读取当前题答案 |
| A09 学习节奏 | 默认每轮 8 题，可继续、练全部或重练；复习固定队列可跨刷新恢复，支持开始新一轮；记录页按待复习题型提供入口，返回保留原筛选 |
| A10 数据读取 | 题库服务端分页/筛选，记录页仅按当前展示的 ID 批量取题；旧不带分页的 API 保持兼容。复习每批 20 项、历史每批 10 项 |
| A11 主题 | 数学画布及 SVG 使用语义颜色，补齐深色映射；旧账号控件回归统一字号和颜色 |
| A12 操作恢复 | 方格只保留一个 Tab 入口，支持方向键、Home/End、空格及撤销；清空可撤销。登录错误在表单内显示并获得焦点，返回路径经统一校验；错误页提供返回练习入口 |
| A13 样式收敛 | 清理三处无教学意义的粗侧边线；保留书本图形边缘及数位当前焦点标记 |

## 浏览器实测

五类播放器代表课节为 U01-L01、U02-L05、U03-L01、U04-L01、U05-L01。每类检查 1280×720、1440×900、1024×768、768×1024，共 20 个组合，没有全页水平或垂直溢出。画布高度如下，较长数位内容仍允许面板内滚动。

| 视口 | 五类画布高度 |
| --- | --- |
| 1280×720 | 约 296–297px |
| 1440×900 | 约 462–463px |
| 1024×768 | 约 344–345px |
| 768×1024 | 约 590–591px |

- 原 1024×768 数量关系画布从 32px 提升至约 344px。常用前后步骤及练习按钮可达。
- 方法页在普通笔记本采用图和原因左右呈现，完整图不再被双层纵滚裁切。围栏关键标签实测约 16px；竖平板极窄方法面板采用同屏紧凑排布，图和原因均可见，保留放大入口。
- 原判断题约 38px 改为实际 24px；同数相除题匹配到独立的 24÷24 分组例题，方法库仍使用默认 235÷18 余数推演。
- 余数第二步放大再 Escape，实际焦点回到“放大演示”，仍保持第二步。错误选项展示重新分组的原因，并可换数字自查。
- 独立纠错实测：u4-03 答 8 后不打开帮助，再改为 7，最新历史正确显示独立答对；旧辅助记录保留。
- 草稿实测：第一题填入未提交值，切到第二题，去记录页再返回，刷新并切回第一题，题号和两个输入均恢复。
- 真实键盘实测：方格右移、空格选中成功；只有一个 Tab 停靠点，清空后撤销恢复所选两格。
- 深色几何画布实测底色为 `rgb(32,47,44)`、文字为 `rgb(220,236,229)`，不再保留刺眼的亮色画布块。
- 题库在三种笔记本/平板视口均无全页溢出，分页固定在底部；普通笔记本可辨多个紧凑题目行，完整条件在右预览阅读。首页首屏可辨四个专题入口。
