## 组件与设计语言

- `apps/web/src/tokens.css` 是全站语义颜色、圆角和层级的唯一来源，`theme.css` 将同一套 token 映射到 Tailwind/Nova。按用户要求使用适合儿童少年的薄荷绿主色，低饱和底色搭配天蓝、杏黄和珊瑚橙分类色；数学图形保留具有教学含义的配色。题干、输入和主按钮保持明确对比。
- 页面只组合共享控件与业务组件。通用按钮、输入框、选择、对话框及反馈样式集中维护；涉及数学作图的业务组件保留在原有领域目录，不强行套进通用 UI。
- 每次迁移一个控件的全部调用点，清理旧封装和对应样式，再迁移下一个。引入新组件不能长期保留同用途的两套实现。
- 题目、输入与主要按钮构成主区域。默认只展示必要条件；答案、详细解析和分步图解按需展开。按钮直接写“提交”“下一题”“看解析”，减少重复提示、口号和无内容副标题。
- 平板主要点击目标至少 44px，提供清晰焦点和字段标签；拖拽有点击或键盘替代；减弱动效时仍能阅读完整推演。手机布局不新增验收工作。

## 依赖引入与替换

1. 先查现有共享组件、`package.json` 和 `pnpm-lock.yaml`，确认不能用现有方案直接满足功能。说明实际调用场景和为何需要新增依赖。
2. 只在使用该库的 workspace 包声明直接依赖，锁定精确版本，使用 pnpm 更新并提交唯一锁文件；共享版本保持一致。检查许可、维护情况、React 与构建兼容性和新增传递依赖。
3. 不引入第二套 UI、图标、动画、拖拽或客户端状态库。第三方组件间接引入重复能力时，检查是否可复用现有底层；必要例外在变更说明中写明范围和清理方案。
4. 替换现有库需迁移调用点、删除旧直接依赖和无用样式，再重新检查锁文件。第三方库源码定制纳入仓库，保留适用的许可和来源说明。
5. 变更后检查格式、类型、构建和相关交互。验证 PC 与平板的布局、焦点和触控；涉及作答、提示或状态迁移时，验证原有答案、错题和 D1 同步行为。

## 状态与动画边界

弹窗开关、当前输入等局部状态留在 React。若后续引入 Zustand，只承载跨组件客户端状态，并复用现有同步接口；不要额外持久化一套答题历史。切换账号必须清理身份相关状态，不能混合不同账号的缓存、草稿与待同步事件。

教学步骤、数学值和判题结果由现有契约与领域代码确定。Motion 只负责状态之间的视觉变化；暂停、前后步骤和减弱动效不能改变数学结果。新增 UI 库不应进入 math-core 或 Worker 的领域逻辑。

## 本轮审查与重构

- 问题：题干、输入、反馈、解析纵向串联，课内多题全部展开；全站存在三份互相覆盖的布局 CSS，缺少深色主题。原界面以蓝白、10px 面板圆角和系统字体为主。
- 新布局：学习与练习使用视口内工作区。题目与作答、演示与要点左右排列，分栏可调；核对、前后题与演示控制固定在相应区域。仅超长题目、解析或知识要点在面板内滚动，不要求滚动整页寻找按钮。课内练习逐题显示。
- 导航：首页与课程目录左侧选单元，右侧选专题或课节。保持路由、单元锚点、主导航名称、教材名称、题目 ID、字段名与判题 API，不更改同步协议、学习记录及错题历史。保留现有页面标题和描述；项目没有此次需要迁移的营销页 URL 或分析事件。
- 连续作答：`QuestionDeck` 只挂载访问过的题，切题时保留输入、提示、判题及解析状态；重练时明确重置。挂载范围在当前页面内，账号切换仍按原有身份边界销毁学习界面。
- 视觉参数：DESIGN_VARIANCE 6 / MOTION_INTENSITY 3 / VISUAL_DENSITY 6。按钮/输入圆角 10-12px，主面板 16px；主操作使用统一绿色，四种分类色只帮助辨识内容。支持系统、浅色与深色主题，偏好仅保存主题设置。界面反馈使用 CSS，并支持减弱动效。
- 依赖：新增 Tailwind 与 Vite 插件、Radix、react-resizable-panels、cva/clsx/tailwind-merge。未出现拖拽、复杂 UI 动效或跨页共享 UI 状态需求，不安装 dnd-kit、Motion 或 Zustand。
- 样式入口：`theme.css` 管理层顺序；`workspace.css` 负责新界面；`legacy.css` 保留数学图形与仍使用的结构规则。已删除旧 `styles.css`、`focused.css`、`practice.css`，清理不使用的展示组件和 381 条无效样式规则，统一由新 token 控制主题。
- 验证范围：PC 桌面与平板横竖视图。jsdom 为 ResizeObserver 提供最小环境替身，真实分栏、视口溢出和可见操作在浏览器检查；原有判题、记录、账号隔离和同步测试继续执行。
- 本轮结果：354 项测试通过，类型、生产构建、格式及包边界检查通过。浏览器覆盖 1440×900、1280×720、1024×768 与 768×1024；实测键盘调宽、填写/核对、图解展开、切题保留状态和双主题。生产练习页的桌面 Lighthouse 性能、可访问性、最佳实践均为 100 分；这是本机测量，不等同于真实用户的网络与设备表现。
