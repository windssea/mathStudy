# 专题练习与试卷导入

平台以练习为主，知识讲解为辅助。入口为专题练习、试卷练习、全部题目和练习记录。保留原有27个课节，但不作为首页主流程。

## 资料和题量

来源：用户提供的 `doc/题目四年级1-2单元`，70张截图，按文件名时间排序。根据卷首、连续题号和内容归属还原为18组；第03组与第02组、第12组与第09组为相同题目内容的再次采集（卷名或版式可能不同）。两组均保留原图与时间位置，选题使用相同ID，避免复制答题记录。

本次录入136道精选题（含改编和2道在线作图题），不是把全部原卷宣称为已数字化测试。每组页面显示“原卷张数”和“选题数”，原图全部可以逐张查看、放大。未选入的题目仍可在原卷中查看。条件看不清、依赖原图细节或不能可靠自动判分的题目不猜测答案。

全站共232题：第一单元108题、第二单元67题、第三和第四单元各12题、第五单元21题、第六单元12题。90道挑战题均有分步图解，全站99题有图解。

## 练习流程

1. 选专题或试卷，点击“练习”。
2. 一次显示一道题，输入、选择或点格作图后核对。也可以查看提示、解析或跳过。
3. 核对后点击“下一题”。解析按需展开，图解逐步显示；有图解时，完整文字步骤另行展开，减少重复内容。
4. 结束显示本次独立答对、跳过和待重练题目，可以重练这些题或重新开始。

试卷内按截图顺序、原卷大题和题号排序，不使用汉字字典顺序排列“一、二、三”。查看原卷不卸载当前作答组件，返回后输入与判分状态仍在。图纸浏览的“放大”只让图片容器滚动，不使整个页面横向溢出。

每次提交、提示使用与错题状态沿用现有学习事件机制，登录后保存至Cloudflare D1并跨设备同步。专题已练数量由同步后的题目记录计算。本轮页码及临时统计保存在当前页面状态，不宣称为带计时和百分制成绩的整卷考试系统。

## 数据和实现

- `content/practice/papers.json`：按时间编排的18组资料，保留每张原文件名及阅读副本地址。
- `content/practice/topics.json`：20个专题入口，其中一、二单元各8个。
- `content/practice/collected-questions.json`：136道选题、来源题号、条件、标准答案、分析和步骤。
- `packages/content/src/depth-questions.ts`：上轮补充的18道原创分析题；原有78题继续保留。
- `QuestionPublic.sources`：试卷、截图序号、原题号；`sourceKind`区分原创、收集和改编。标准答案及解析不在公共列表接口中返回。
- `practice`随内容版本写入D1的发布清单；题目仍写入原有发布题表，不新增或清空账号和历史记录表。
- 原图保持在用户资料目录，Git忽略原始截图；70张WebP阅读副本约9.1 MiB，作为Cloudflare Worker静态资源发布。

API：`GET /api/v1/practice`、`GET /api/v1/practice/topics/:id`、`GET /api/v1/practice/papers/:id`。判分和解析沿用原接口。

## 作图与图解

方格作图使用不超过80位的0/1字符串表示选格。服务端检查面积、连通性、必要时的周长、是否为实心长方形，以及原有方格是否保留。接受平移、不同长宽等符合题意的画法，不按某一张示例图机械匹配。即时核对和D1同步统一调用同一个判分函数。

图解包含试商表、余数还原、按人数累加的路程、收费方案表、公共边、靠墙围栏、方格外边界和旋转剪裁。数表、数量条和运算流程按实际内容确定高度，避免固定画布的大片空白。

## 验证

自动检查包含来源顺序、18组70图的完整性、重复采集映射、232题标准答案判分、136题导入协议、图解数据、作图的等价正确答案/错误形状/删除已知格、在线判分与同步判分一致性，以及逐题练习、原卷切换保留答案、在线作图流程。

按PC Web和平板验收，不扩展手机适配范围。浏览器已验证1280级桌面与768宽平板的首页、原卷分页、实际作图和图解；平板方格点击区域约46像素，无页面横向溢出。

本机Windows的Vite/Miniflare代理在快速连续冒烟请求中曾返回`fetch failed`，独立接口请求和浏览器流程正常；保留严格状态断言，发布以线上D1与Worker的完整冒烟结果验收，不用重试掩盖失败。

新增作图题的双设备验收可使用 `pnpm exec tsx scripts/smoke-sync.ts --unit practice --write`，仅在明确要写入测试记录的本地环境使用。生产验收不加`--write`，只检查会话与同步快照。
