版本：v1.0 设计基线 · 日期：2026-10-19 · 项目：mathStudy

## 基线与状态

当前项目已实现首页、目录、第一单元五课、第二单元七课及活动、第三单元四课、第四单元三课、第五单元七课、六单元原创题库，以及 D1 内置账号和跨设备学习同步；实际交付边界见[开发进展](./05-开发进展.md)。01 至 04 规定整体目标系统，不表示全部接口、后台与云服务已经实现。`specs` 中仍是设计样例，运行内容位于项目 `content` 和 `packages/content`。

教材依据为本目录的[原始 PDF](./苏教版数学四年级上册.pdf)。文件共 131 个 PDF 页面，版权页载明 2026 年 7 月第 1 版，ISBN 978-7-5743-2533-3。目录为六个单元、四个专题活动和期末复习，不能套用旧版同名教材目录。教材事实与平台拟定课节分别标注在课程映射文档中。

原始分析中的“结构化内容、交互动画、受约束 AI 生成、人工审核、Cloudflare 部署”保留；“初高中函数优先”调整为本册实际内容；基本答题、学习进度与错题复习进入首期完整版本。首个内测切片先完成第一单元及面积实验，再扩展到全册。

## 核心决策

1. 首页是教材学习首页，默认教材通过服务端配置指定，不在页面代码中写死。
2. 区分教材系列、教材版本、源文件修订、课程内容发布版本；新教材不覆盖旧教材学习记录。
3. 教材目录是课程主线，知识点用于关联和复习；每项正式教学内容必须有教材依据和教研审核记录。
4. 动画采用固定模板和 JSON 数据，首期以竖式、面积、数量关系、数位和运算顺序为重点。
5. 学生优先使用已审核内容；AI 帮助编辑制作草稿，并在限定内容范围内提供提示。
6. 全册可用以六单元、四活动、期末复习的覆盖和验收为准，不以生成题目数量代替教学质量。
