# 图示方法与儿童阅读设计

日期：2026-10-29。适用于 PC 与平板浏览器。

## 设计方向

面向四年级儿童的数学演示板：先看图，再看当前一步的原因，最后用易错判断检查理解。保留 Nova / Radix、Lucide、CSS Grid 和原有确定性数学引擎，不增加依赖。

- 配色：纸面 `#fcfdfb`，薄荷底 `#eef5f0`，主绿 `#087b68`，已知量蓝 `#285e99`，易错珊瑚 `#b52f47`，提醒黄 `#fff2cf`。深色模式使用独立的语义颜色映射。
- 字体：微软雅黑 UI / 微软雅黑、苹方、Segoe UI 系统字体栈。正文18px、界面16–17px、题干22px、标题24–32px。图内标签按可用空间缩放，提供独立放大模式。
- 布局：方法库采用左侧单元导航、右侧演示板。题型切换、单元联系和练习入口合并一行；图形与当前原因优先左右排列。练习仍保留左题右答，宽屏查看方法时给右区65%空间，返回作答恢复先前比例；窄平板保留原分栏。前后步骤和前后题控制固定在各自区域。
- 取舍：取消堆叠的全部步骤、重复标题及常驻长解析。颜色只表示已知、本步、错误等数学角色，配合文字、虚线和数位；不依赖颜色辨认正确答案。方法示例明确标为“例题”，不当作当前练习答案。

## 图解与教学交互

`packages/animation-engine/src/methods.ts`为全部42类方法提供纯数据故事板，每类包含三个可前后回看的状态，以及一组独立的易错判断和解释。使用线段、矩形、方格、数位表、数轴及部分积示意，不使用截图或位图。

重点演示包括靠墙围栏只计三边、剪角后边界替换、内部公共边、面积单位的10×10格、余数与整份装载、段数与切口、重新分组中的不变量、运算顺序、编码补零、四舍五入及乘法十位部分积。示意图明确标注不按实物比例；数量关系以算式与标注为准。

默认手动查看；播放由学生触发，每步停留6秒，可暂停或重看。切回作答、关闭放大模式时停止播放。放大模式复用Radix Dialog，支持焦点约束和Escape关闭。方法要点和单元联系复用Radix Popover，按需阅读。

`MethodDiagram`只绘制故事板，`MethodDemonstration`只选择帧与显示判断反馈；不承担判分或学习记录。查看方法继续走原有辅助事件协议，独立答题、错题、D1和题目ID保持兼容。

## 验证

新增测试约束42类覆盖、不同帧与有效几何坐标，核对围栏、切口、单位方格、装车与部分积等关键数学关系；覆盖易错判断、隐藏答案、放大与Escape、手动与自动播放、暂停、切回作答及输入保留。

浏览器检查桌面、普通笔记本、横向与竖向平板，复核全页溢出、可见控制、字号、缩放与双主题。长解释保留区域内滚动，独立放大模式用于较小面板和复杂例题；不以缩小正文或滚动整页换取空间。

本轮验证结果：25个测试文件、366项测试通过；类型、生产构建、格式、包边界、内容源文件哈希及生产包D1接口检查通过。界面覆盖1440×900、1280×720、1024×768与768×1024视口，复核浅色/深色、放大与关闭、方法/作答切换以及分栏恢复。
