## 4. 知识点与前置依赖

知识点 ID 使用稳定语义名，如 `arith.division.two_digit_divisor`、`geometry.rectangle.area`、`number.place_value.base10`。课节与知识点多对多关联；相同知识点在不同教材中的目标、例题、方法和顺序分别记录。

首期关键依赖：表内乘除与位值理解 → 两位数除法；长度测量 → 周长；单位方格 → 面积公式 → 面积单位换算；乘法意义 → 单价/速度关系 → 综合数量关系；万以内计数 → 万级和亿级 → 近似数；两位数乘法 → 三位数乘两位数。前置知识若来自前册，以“补充知识”短卡呈现，并标明本册之前已学，不虚构成本册课节。

每课限定 `allowedMethods` 和 `allowedKnowledgeIds`。例如本册应用题使用分步算式、线段图、数量关系和表格，不默认用一元一次方程或比例方程讲解。教材已经使用字母表达公式，应保留；不能以“避免超纲”为由删去教材中的 `S=a×b`。

## 5. 内容生产与审核要求

每个课节交付：学习目标、教材页码、前置知识、短讲解、交互任务、示范例题、分层提示、随堂练习、常见错误、复习关联和审核记录。基本节点建议 3–6 道原创或已获授权的练习；开放活动采用任务表和评价量规，数量不等同于普通题数。

示例与教材原题、基于教材改编、原创同知识点题分别标记 `sourceKind`，记录是否改变数值、情境和图形。禁止把 AI 生成题自动标为教材原题。教材正文/插图/封面资源是否公开展示由资源权限控制；学习首页可先用书名和自制几何封面，不以开放整本 PDF 为前提。

审核分三项：数学正确性、与本版教材一致性、教学表达与交互可用性。三项均通过才可发布。练习答案由确定性规则复算；开放题用量规和人工判断；每条来源锚点含版次、PDF 页序、书内页码、题/例号和可选区域框。

## 6. 后续教材接入

同系列下一册、新版同册、其他出版社教材分别建记录。文件哈希相同则提示重复；ISBN 相同但文件不同进入源文件差异核对；新版本可复用知识点与模板，必须重新核对页码、教学目标、允许方法和练习。

接入验收至少包括：目录与 PDF 对齐、无跨教材内容引用、所有必修节点有已审核内容、活动顺序保留、正确首页/教材选择行为、旧教材作答记录可回看。第二本教材应在测试中通过数据导入完成，不改首页或课程路由代码。
